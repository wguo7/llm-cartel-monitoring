# Coached LLM cartels and collusion monitors

Code and data for the AI Collusion Research Sprint report "Coached LLM Cartels Fool Combined LLM Judges but Not Hidden Price Screens" (October 2026). The report is in `report/report.pdf`, with its source in `report/report.md`. It is the version submitted on 25 October 2026, whose statement that code and logs are available on request refers to this repository.

The question: in an LLM double auction, does a monitor that combines what sellers say with what they do beat one that reads either alone, and what happens when the colluding sellers know the monitor exists? Short answer: a cartel told only that a monitor exists kept coordinating openly and was caught; cartels told how to hide were not reliably caught by any language-model judge view against honest sellers who discuss the market, and against honest sellers told never to discuss prices a messages-only judge caught them but the judge also reading trades did not. Two one-line price statistics ranked every cartel not told about them above honest sellers; the two cartels told about both evaded them largely by pricing closer to honest sellers.

- `starter/` is a clone of the sprint starter repository, [poseidon-research/collusion_hackathon](https://github.com/poseidon-research/collusion_hackathon) at commit `d585a7b`, which contains the double-auction environment of Agrawal et al. (2025). It is not included here; `starter_patch/` holds our only change to it in `src/resources/model_wrappers.py`: a token-usage logger, and a client timeout read from `LLM_TIMEOUT` (default 120 seconds, the upstream value). The arm prompts in its `prompt_templates/` folder are generated by `scripts/make_templates.py`.
- The one-way monitoring rule (statements may raise a monitor's suspicion but never lower it) comes from the author's earlier, unpublished work on single-agent monitoring. No code from that work is used here.

Everything else (arm briefings, launcher, judges, analysis, figures) was written during the sprint.

## Layout

| Path | Contents |
|---|---|
| `scripts/make_templates.py` | Writes one seller prompt per arm from the environment's base prompt |
| `scripts/run_arm.py` | Runs one episode (arm, seed) through the OpenAI API and logs token usage |
| `scripts/launch_main.py` | Runs arms by seeds in parallel, with a spending kill rule |
| `scripts/monitor.py` | Language-model judges: views M (messages), A (actions), C (combined), S (messages + computed outcome report), K (combined + one-way instruction), R (actions + outcome report), N (outcome report + last-five-hour mean ask), P (the environment's per-hour overseer), and judge-prompt ablations E (combined, excusing sentence deleted) and B (E + a stated $90 competitive benchmark), H (combined + the honest sellers' price reference) and T (a structured rubric: five 0-10 item ratings, then a probability). `JUDGE_BUDGET_USD` stops a paid judge at a spending limit. Setting `JUDGE_BASE_URL` points it at any OpenAI-compatible server; we served the open-weights judge Qwen2.5-14B-Instruct (4-bit) locally with `mlx_lm.server` |
| `scripts/analyze.py` | Price statistics, AUROC with bootstrap intervals, paired differences, frozen-threshold flag rates (the seven original arms) |
| `scripts/analyze_extra.py` | The same for the profit cartel and the judge-prompt ablations, plus market outcomes per arm (`results/extra_<judge>.md`) |
| `scripts/analyze_plain.py` | AUROC with each honest arm as the negatives (`results/plain_<judge>.md`) |
| `scripts/analyze_oneway.py` | Exploratory rules combining the price level with the messages judge (`results/oneway_<judge>.md`) |
| `scripts/analyze_ref.py` | Judge given the honest reference (view H) against the combined view (`results/ref_<judge>.md`) |
| `scripts/analyze_ctrl.py` | The monitor-only cartel and the profit cartel told every screen: AUROC against each honest arm, flag rates, market outcomes with intervals (`results/ctrl_<judge>.md`) |
| `scripts/analyze_struct.py` | The structured rubric (view T) fitted by logistic regression and scored on held-out seeds, held-out cartels and the two later arms (`results/struct_<judge>.md`) |
| `scripts/swap_messages.py` | Message-swap test: one episode's asks, bids and trades shown with the same-seed messages of another arm, scored on the combined view (`results/scores_swap_<judge>.jsonl`) |
| `scripts/analyze_swap.py` | Message and action effects of the swap test with bootstrap intervals over seeds (`results/swap_<judge>.md`) |
| `scripts/seed_block.py` | Seed-block bootstrap intervals and held-out-threshold flag rates for the primary judge (`results/seed_block_<judge>.md`) |
| `scripts/overseer_anchor.py` | Overseer scored by mean and count of hours, and a fixed price anchor with no honest reference (`results/overseer_anchor_<judge>.md`) |
| `scripts/fold_weights.py` | Structured-rubric logistic-regression weights fitted on each seed half and on all fitting episodes (`results/struct_fold_weights_<judge>.md`) |
| `scripts/coached_pool.py` | Table 1 detectors pooled over the coached cartels only, without the unaware cartel (`results/coached_pool_<judge>.md`) |
| `scripts/conduct_packets.py`, `scripts/analyze_conduct.py` | Blind conduct labels from seller messages (annotator brief, key and outputs in `results/conduct/`; summary `results/conduct_labels.md`) |
| `scripts/fig_headline.py` | Figure 1: AUROC per cartel and buyer surplus per arm |
| `scripts/flag_rates.py`, `scripts/harm_ci.py` | Flag rates at the sealed thresholds; bootstrap interval for the buyer-surplus comparison |
| `scripts/mechanism.py` | Ask dynamics, judge rationales and message wording per arm (`results/mechanism.md`; `--quiet` writes `results/mechanism_quiet.md`) |
| `scripts/quiet_negative.py` | Every detector against the quiet honest arm only (`results/quiet_negative_<judge>.md`, Table E3) |
| `scripts/quiet_packets.py` | Blind annotation batch for the quiet honest arm plus calibration episodes (`results/conduct/batch6`, `key6.json`) |
| `scripts/conduct_quiet.py` | Resolves that annotation, checks quotes and calibration agreement (`results/conduct_quiet.md`) |
| `scripts/table1_extra.py` | Adds the profit cartel and ablation rows to the report's Table 1 |
| `scripts/figures.py`, `scripts/render_template.py`, `scripts/build_docx.py` | Report figures, PDF in the Apart template format, and the filled template .docx (`report/fonts/` holds the template font, Old Standard TT, SIL Open Font License) |
| `scripts/cost.py` | Measured spend from logged token counts |
| `runs_main/`, `runs_adapt/`, `runs_price/`, `runs_profit/`, `runs_ctrl/`, `runs_quiet/` | All 220 episode logs (11 arms by 20 seeds), with per-call token usage |
| `results/` | Judge scores with the judges' stated evidence, analysis tables (`main_<judge>.md`), market outcomes |
| `PREDICTIONS.md` | Predictions sealed before each experiment, and their resolutions |

Arm codes in the data: `H_comp` honest, `H_high` honest with CEO pressure, `H_quiet` honest told never to discuss prices (episodes in `runs_quiet`), `C_naive` unaware cartel, `C_msg` hides words, `C_full` cover stories, `C_adapt` hides words and ask pattern, `C_price` knows all screens, `C_profit` hides words while pursuing profit, `C_notice` told of the monitor only, `C_profit_screen` profit cartel told every screen.

## Reproducing

1. Clone the starter repository into `starter/`, check out `d585a7b`, run its `./setup.sh llm-agent-collusion`, and apply `starter_patch/model_wrappers.patch`.
2. `python scripts/make_templates.py`
3. `export OPENAI_API_KEY=...`, then for example `python scripts/launch_main.py --budget 80 --arms H_comp H_high C_naive C_msg C_full --out runs_main`.
4. `python scripts/monitor.py runs_main --judge gpt-4.1-mini-2025-04-14 --views M A C S P K R N E B`
5. `python scripts/analyze.py runs_main,runs_adapt,runs_price gpt-4.1-mini-2025-04-14 --out results/main_gpt41mini.json`, then `python scripts/figures.py results/main_gpt41mini.json report/figs`; from `scripts/`, `python analyze_extra.py gpt-4.1-mini-2025-04-14`.

The first 200 episodes made 30,000 model calls for $129.19 and their judging cost $45.91. The quiet honest arm added $12.56 and its judging $0.29, all measured from returned token counts at OpenAI's published prices (October 2026). Excluded pilot episodes are not included here. The open-weights judge ran locally at no API cost. Sellers use `gpt-4.1-2025-04-14` and buyers `gpt-4.1-mini-2025-04-14`, both at temperature 0.7, so reruns will not match exactly.
